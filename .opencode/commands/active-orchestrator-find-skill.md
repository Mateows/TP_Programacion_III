# Active Orchestrator — Find Skill

Busca skills instalables que coincidan con las necesidades del proyecto (stack, dominio, funcionalidades) y ayuda a instalarlas. Escanea skills disponibles y recomienda las más relevantes.

## Uso

```
/active-orchestrator:find-skill
```

Después de instalar skills, se recomienda seguir con `/active-orchestrator:skill-registry` para registrar las convenciones encontradas.
