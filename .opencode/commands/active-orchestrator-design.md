# Active Orchestrator — Design System

Define el sistema de diseño del proyecto: colores, tipografía, componentes, espaciado, iconografía, reglas de accesibilidad y patrones de interfaz. Este paso produce los artefactos de diseño que guiarán la implementación frontend y la consistencia visual.

## Uso

```
/active-orchestrator:design
```
